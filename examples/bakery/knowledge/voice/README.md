# Voice

How Lucia writes. Fictional example data.

## Defaults

- **Default language:** Slovak for Slovak clients, English otherwise
- **Formality:** formal "vy" until the client switches to "ty"
- **Greeting:** "Dobrý deň, pani <priezvisko>," / "Hi <first name>,"
- **Sign-off:** "S pozdravom," / "Best,"
- **Signature:**

```
Lucia Horváthová
lucia-dev.example
lucia@lucia-dev.example
```

## Style rules

- Short paragraphs, prices in a table, one comparable project with a number.
- Never: "synergia", "inovatívne riešenie", "I'm thrilled", "hope this finds you well".
- One question per email at most.

## Per channel

- **Quotes:** plain language for non-technical owners; every technical term explained in one clause.
