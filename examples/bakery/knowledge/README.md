# Knowledge base

The source of truth for the `office:` and `council:` agents. They answer from these files and the sources they cite, not from general knowledge. Plain Markdown, so the folder also opens as an Obsidian vault.

| Path | What lives there | Written by | Read by |
|---|---|---|---|
| `profile.md` | Who you are, services, proof projects, ideal clients, hard rules, sites, job search | you, `/office:setup` | everyone |
| `pricing/` | Rate, terms, add-on prices; past quotes in `quotes/` | you, quote-builder | quote-builder, pricing-analyst, council |
| `voice/` | Writing style; real messages that worked in `samples/` | you, librarian | outreach-writer, copywriter |
| `clients/` | One file per company: `<slug>.md` | researcher | everyone |
| `sources/` | Digests of videos, courses, articles | librarian (`/office:learn`) | everyone |
| `council/` | Full transcripts of every `/council:vote` | council | you |
| `leads/` | Lead lists, desk runs and outreach drafts | lead desk, outreach-writer | you |
| `sites/` | Site health snapshots | site desk | you |
| `jobs/` | `applied.md`, `dismissed.md`, job desk runs | job-scout | job-scout, you |

## Rules for agents

1. **Cite.** Every number or claim taken from here names its file; every claim from outside names its URL.
2. **Compress.** Files are summaries a busy person reads in 2 minutes. No raw transcripts or dumps.
3. **No secrets.** Never store passwords, API keys or bank details, or other people's personal data beyond name, role, company and public profile URL.
4. **Update, don't duplicate.** Edit the existing file for a client or topic.
5. **Absolute dates** (YYYY-MM-DD).

The more real data you add (sent quotes, messages that got replies), the better the agents get.
